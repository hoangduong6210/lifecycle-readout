Title: Monotonicity of Temporal Graph Readouts: Exact Certificates and Predictive Limits

Compile main.tex twice with pdfLaTeX in a complete TeX distribution. The package has been verified with Tectonic 0.17.0 (XeTeX); a separate pdfLaTeX run was not performed. Keep external figures in the same directory. The reference list is embedded in main.tex, so BibTeX is unnecessary for this version; references.bib is included for editing.

Fig1 through Fig8 are vector PDF and EPS artwork. Captions are in the article. The aggregate CSVs and Supplementary_Data_Guide.txt contain mathematical examples and reported model-evaluation summaries, not source interaction records or trained checkpoints.
