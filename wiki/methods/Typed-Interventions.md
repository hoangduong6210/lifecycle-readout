# Typed Interventions

An intervention overrides a declared state or driver in the interpretable
branch and re-evaluates that branch. Admission requires typed input validation,
direction gates, no-op equality, reversibility, and scored-output invariance.
These are implementation tests, not proof of a discovered causal graph.
