# License and Assets

No project code license was present in the migration source. License selection
is blocked on owner review; no MIT, Apache, or other grant is implied. Dataset
terms, citations, and redistribution permission require a separate registry
review. `IEEEtran.cls` retains its own LPPL notice and is not relicensed by this
project. Named and blind manuscripts must remain explicitly distinguished.
