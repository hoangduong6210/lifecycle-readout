# Project Limitations

- Imported results predate the formal release contract and are not frozen.
- The current empirical scope is CoEdit; cross-domain lifecycle semantics are not established.
- The hand-specified lifecycle structure is not a discovered causal model.
- Internal causal coherence is not external error calibration or physical validation.
- Score invariance is an implementation property that must be tested on the admitted instance.
- No new training, intervention benchmark, or external validation was run in the split.
